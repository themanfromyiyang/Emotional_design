# See through your eyes · 万物视野 v2

动物数据库 → 实时论文检索 → 带来源的视觉说明 → 使用示例或自己的图片生成视觉转译。

没有预设动物列表，没有预生成的动物视觉图。首页从 iNaturalist 动态读取动物条目，支持名称／学名搜索、分类筛选和分页。

卡片默认照片不可用时，会按当前页批量读取物种详情，从其他照片中选择 CC0、CC BY 或 CC BY-SA 照片，并保留署名和来源链接。确实没有符合条件的照片时才显示占位图。

名称搜索使用 iNaturalist 的 autocomplete 接口，依据实时返回的学名、俗名与别名优先展示精确匹配；中文须包含完整搜索词，避免单字误匹配。搜索最多获取 30 条相关候选并在本地分页，达到上限时提示细化名称。未输入名称时仍使用普通数据库分页浏览；分类筛选通过对应分类群 ID 限定。

## 启动

需要 Node.js 22 或更高版本。不需要安装依赖。

```powershell
cd 'C:\Users\student\RiderProjects\Emotional_design\see through your eyes'
npm start
```

打开 **http://127.0.0.1:5180/** 。按 Ctrl+C 停止服务。

现在直接打开 index.html 或 Rider 静态预览时，会检查 5180 后端的服务标识；若可用则自动跳转到完整网站，保留搜索条件。后端未启动时保留启动提示和手动入口。正式入口仍为 http://127.0.0.1:5180/ 。HTML、JS、CSS 禁用缓存，并给入口资源添加版本号，避免旧脚本导致不同步。如果修改了 `.env` 或服务端代码，需要重启 `npm start`。

## 配置 GPT

复制 `.env.example` 为 `.env`，在本机填入自己的 `OPENAI_API_KEY`，保存后重启服务。

```dotenv
OPENAI_API_KEY=你的密钥
OPENAI_RESEARCH_MODEL=gpt-4.1
OPENAI_IMAGE_MODEL=gpt-image-2
PORT=5180
```

密钥不进入浏览器、不输出到日志、不提交 Git。模型可按账户权限修改。账户需要对应模型权限与可用 API 额度。生成调用会按账户计费。

**未配置密钥时：** 动物搜索、物种选择、实时论文检索、候选来源浏览和图片本地预览可用；不会伪造视觉说明或生成图。

## 使用

1. 搜索动物，或在动态图鉴中选择一个条目。
2. 页面自动检索目标学名、同属和同科相关视觉文献。无密钥时展示候选论文；有密钥时由 GPT 阅读可获取摘要并输出结构化视觉说明。
3. 说明区显示研究对象、直接／近亲证据、引用与未知部分。检索命中并不代表该动物被实测；没有足够证据时禁止生成。
4. 选择通用“池畔色彩场景”示例，或上传 PNG、JPEG、WebP。最大 8 MB；浏览器缩放长边至 1536 像素后预览。
5. 点击“生成视觉模式图”，后端把当前研究约束与原始图片发送给 OpenAI Images Edits。原图不会提前上传。
6. 生成后拖动分界滑杆对照，并下载结果。

示例是本站原创矢量插画，包含不同颜色、花草、水面与小径；不是照片，也没有预先应用动物视觉效果。生成图不自动存盘，可由用户主动下载。服务端研究会话保留在内存两小时，重启后失效。

## 数据与边界

- iNaturalist 提供分类、常用名、学名、观察数量和开放许可照片。只显示 CC0、CC BY、CC BY-SA 照片并保留署名链接；其他照片用文字封面替代。观察数不是种群数量。
- 数据库搜索缓存 5 分钟、详情缓存 24 小时，请求合并并以至少 1.1 秒间隔串行发送，故障时可使用旧缓存并标记。
- Europe PMC 检索每次选择时执行，收集本物种前 8 条、属与科各前 5 条相关结果，去重后作为候选来源。不是全网全面综述，也尚未接入纪录片。
- GPT 根据检索到的摘要生成说明。引用 ID 必须指向已获取的来源，没有摘要的题录不能单独支持结论。语义判断仍可能出错，正式科学使用需要人工审核。
- 图像生成仅使用报告内有证据支持的视觉转译约束。普通 RGB 场景没有真实紫外、偏振或多光谱信息，结果是研究启发的艺术解释，不是动物主观视觉的准确复原。

## 验证

```powershell
npm run check
npm run test:live
```

`check` 验证脚本、DOM 引用与离线自动测试，包括动态查询、许可过滤、文献去重、缺少密钥、故障提示、引用校验、上传验证、生成请求结构、同源保护和静态预览 HTML 报错。

`test:live` 只访问 iNaturalist 与 Europe PMC，以帝王蝶验证任意物种流程，不调用付费 OpenAI API。已实测返回本种、同属、同科共 13 篇去重候选论文。另已确认 `wolf` 搜索正常返回包含 `Canis lupus` 的结果。

当前环境无 OpenAI API Key，真实 GPT 说明与图像生成未做付费端到端验收；请求格式与阻断条件以 mock 测试验证。浏览器控制受环境限制，未完成截图级验收。

## 文件

- `index.html` / `style.css` / `app.js`：数据库与研究／生成工作区。
- `api-client.js`：请求解析与静态预览诊断。
- `inaturalist.cjs`：动态动物查询、分类详情、缓存和限流。
- `research.cjs`：论文检索、GPT 说明、来源校验、图片编辑。
- `server.cjs`：本机服务与 API；只公开白名单静态资源。
- `assets/example-garden.svg`：原创通用输入示例。
- `.env.example`：配置模板；`.cache/` 与 `.env` 被 Git 忽略。

此版本仅用于本机，监听 127.0.0.1。线上部署前需另行设计账户、调用额度及持久任务管理。
