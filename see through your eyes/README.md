# See through your eyes · 万物视野

一个无需安装依赖、无需 API Key 的本地静态网站。首版包括 1 个共同场景与 5 个视角：人类、西方蜜蜂、家犬、小天鹅、赤狐。

## 打开

直接双击 `index.html` 即可使用全部主要功能；或在此目录运行 `npm start`，打开 http://127.0.0.1:5180 。按 Ctrl+C 停止服务。

`npm run check` 检查脚本语法、物种证据字段、赤狐直接来源、页面元素引用和图像资源。无依赖安装步骤。

## 体验

- 选择或搜索生物，切换同场景的 GPT 生成视觉示意。
- “与人类对照”开启滑杆；滑杆支持键盘方向键。
- “为什么这样看？”显示原始研究、转译方式与局限；按 Esc 关闭。
- 小天鹅带视野构型的概念叠层；宽度不代表实测角度。
- 赤狐引用包含本物种的感光色素研究，与犬共用二色艺术示意。
- 支持窄屏、键盘访问、系统减少动态偏好。外部论文链接需要联网；本地图片与页面无需联网。

## 文件

- `index.html`：页面结构。
- `style.css`：米白纸色、深绿字色、衬线排印的自然图鉴视觉。
- `species.js`：结构化物种资料与可追溯文献。
- `app.js`：搜索、选择、对照、研究弹窗、全屏。
- `assets/park-vision-atlas.png`：GPT 生成的四联画，1536×1024。
- `RESEARCH.md`：证据整理、生成记录与扩展规范。
- `server.cjs`：仅监听本机的静态服务。

## 状态与边界

这是研究启发的艺术解释原型，不是经过光谱校准的动物视觉模拟器，也没有覆盖地球所有物种。浏览器使用已经生成的图像，不在点击时调用 GPT。四联画整体构图一致，但生成过程存在局部细节漂移。

参考地址 https://thenaturelibrary.org/ 在制作时返回 Vercel 安全验证页，未能核对其真实版式。因此本版采用独立的自然图书馆式排版，未声称精确复刻。未发布到线上。

交付检查：脚本语法、数据字段、页面引用、图像尺寸检查通过；本地页面与 PNG 请求均返回 HTTP 200。浏览器控制宿主不可用，原生 Edge 窗口恢复也失败，尚未完成实际浏览器交互及截图级视觉验收。预览服务已停止，仍可直接打开 HTML，或使用 `npm start` 重启。

## 扩展

新增 `species.js` 记录并增加对应生成图像。直接证据优先，近亲证据需写明研究对象与同种／同属／同科层级；不要仅凭亲缘关系复制精确视觉参数。将全物种覆盖视为逐步研究和审核的图鉴工作，而非自动补齐未知数据。
