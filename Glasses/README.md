# AI 视角眼镜 · 外观概念

这三组图用于探索一款**通用的视角切换眼镜**。设计重点是帮助佩戴者重新注意眼前环境；外观接近日常光学眼镜，以柔和的自然色、真实材质和低存在感的感知点表达智能能力，不绑定某个具体生物。

## 第二版 · 优先评审

第二版增加了镜片上缘的小型光学片、镜腿触控区和自然收束的电子模块。第一人称视角图在真实环境的右上方提供一个小型辅助视窗，用同一地点的另一观察角度表达“转换视角”；视窗以外的环境保持清晰。参考幻灯片的页面排版和具体生物内容没有进入这些图。

## 生成提示词方向

- **苔绿产品图：** 圆角方形、半透明苔绿色板材、暖钛色镜腿、镜框外侧隐蔽感知点；亚麻和石灰石上的自然光产品摄影。
- **苔绿佩戴图：** 保持产品图的镜框外观；成年人在林荫公共步道停下观察环境，胸像三分之四角度，真实皮肤与自然光。
- **琥珀产品图：** 柔和圆框、蜂蜜琥珀色板材、深铜色镜腿；浅橡木桌与纸张上的暖色自然光产品摄影。
- **琥珀佩戴图：** 保持产品图的镜框外观；成年人坐在城市公园长椅上看向周围，纪实摄影质感。
- **砂石产品图：** 椭圆方形、浅砂石色哑光镜框、香槟金镜腿；手工纸与河石上的清晨自然光产品摄影。
- **砂石佩戴图：** 保持产品图的镜框外观；成年人在公共河滨步道观察环境，纪实摄影质感。

共同约束：透明镜片、可日常佩戴、自然光、无品牌文字、无悬浮界面、无霓虹或科幻造型。

第二版提示词方向：在每款第一版镜框上加入一个小型、半透明的镜片光学片，改造镜腿轮廓并加入可触摸控制区；佩戴图沿用原有人物与环境，只更新眼镜。第一人称图使用相应配色的镜框边缘和单个右上角小窗，窗内显示同一场景的另一观察角度，无文字、图标和特定生物。
